# ts-molfair-ios

The task does not specify project settings, so I chose common, conservative ones. The app targets iOS 17 (the version suggested by Xcode) and iPhone only, since it is a single list screen and iPad support would add effort with no benefit. I kept the Swift 5 language mode, which is Xcode’s default for new projects. Core Data objects are not Sendable, so Swift 6 strict checking would add noise unrelated to the task. Only plain ItemRow structs cross threads. I also used the classic concurrency model (Default Actor Isolation set to nonisolated, Approachable Concurrency off), so code is not implicitly on the main actor. MainActor is set explicitly on the presenter and the view controller, and Core Data work runs inside context.perform, so the thread is always clear.
